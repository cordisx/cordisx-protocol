# Entity settings navigation v1

Normative additive capability. Public import: `@cordisx/protocol/entity-settings-navigation/v1`.

`get({identity})` reports whether the Host can open settings/details for the exact
frozen Agent definition identity. `open({identity})` resolves again at the time
of activation. Both accept only `agentId` and `revision` inside `identity`.
They do not acquire an Agent, create/resume a Session, edit an entity, or accept
an owner, provider, source, URL, route, or contribution identifier from a caller.

The Host MUST authenticate the calling source/plugin/generation and reject a
retired/disposed caller. It MUST select exactly one visible, authorized target
whose subject matches both identity fields; its declared parent/root must also
be available and authorized. Missing, ambiguous, inaccessible or stale targets
return `target-unavailable`; they MUST NOT fall back to a latest revision or a
similarly named entity. Navigation availability is not entity-read permission.
The Host retains its own navigation history and return behavior. Opening a target
changes only presentation/navigation, not entity or execution state.

A prior `available` result is advisory, never authorization. `open` revalidates
caller and target before dispatch. Invalid closed request shapes return
`invalid-identity`; unavailable Host and caller return their typed codes.
No opaque capability registry is needed because every operation resolves anew.
The Host MUST avoid leaking private owner, route or discovery details in results.

This capability is independent of Session detail navigation and Manager content
contribution declarations; their frozen versions are unchanged. A Host without
this service is unsupported. Consumers may explain unavailability, but cannot
claim a migrated Settings action is equivalent until a supported path is present.

Schemas: [request](../../../schemas/entity-settings-navigation-request.v1.schema.json),
[availability](../../../schemas/entity-settings-availability-result.v1.schema.json),
[result](../../../schemas/entity-settings-navigation-result.v1.schema.json).
