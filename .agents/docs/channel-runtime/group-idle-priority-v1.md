# Group Channel idle model priority v1

An authenticated group administrator may explicitly authorize an ordered list of later models from the current provider for the exact bound group conversation. The Host first discloses the models, that the existing native conversation and project are retained, the probe cost and the rule lifetime. Administrative authority comes from current Host policy and exact transport identity; a platform role or a model's claim is insufficient. The rule is revocable and bounded in time. It neither grants access to another conversation nor authorizes a provider change or linked history transfer.

Before dispatching an input, the Host requires an idle, uniquely bound source and a current rule. It confirms the exact existing selection, policy, group identity, administrator authority and model permissions for each queued sender, including explicit denies. It preserves input order. A healthy current model remains selected, even if it is not first in the configured list. Only a bounded real synthetic no-tool probe that establishes current-model unavailability permits trying the disclosed candidates in order. Unsupported or inconclusive source probes do not authorize a switch. The Host preserves the original project and execution settings and does not initiate or replay a business turn during selection.

The Host durably reserves an uncertain operation before a native effect and rechecks source selection, permissions and binding at the effect boundary. It proceeds with the queued input only after the original session and selected model are confirmed. If the effect or acknowledgement is unknown, the input remains in reconciliation and is not dispatched or automatically retried. A stopped process must not turn an interrupted reservation into a new selection. A group rule may cover later eligible group senders without requiring a fresh confirmation for each message; changing the administrator, binding, source selection, policy or configured priority invalidates it.

Cross-provider group continuation requires a separate contract and proven group-only history provenance. A shared native session can contain private or other-group turns; a group administrator's grant does not authorize disclosing those turns. Older Hosts must reject persisted group rules rather than treating them as personal grants. This contract does not cover running turns, multiple bindings or unprobeable source services.
