# Group-scoped linked priority v1

This optional successor extends [group idle priority v2](group-idle-priority-v2.md) with explicitly authorized cross-provider linked continuation for an idle, uniquely bound group. An administrator with group management and target model authority confirms the exact ordered candidate list and that a destination may receive a bounded projection of recorded group input and confirmed sent replies. The disclosure states that older, unrecorded, unconfirmed, attachment, tool and reasoning history is omitted; the projection is not a full native conversation or checkpoint.

The Host derives every projected user entry from a previously dispatched, accepted input and every assistant entry from the matching confirmed delivery to that same adapter, account, tenant and group. It excludes unresolved, unconfirmed, other-conversation and provenance-unknown content. It records a bounded, stable projection and scopes every on-demand read to an authenticated active destination turn, current group binding, administrator authority, sender dispatch rights and explicit denials. Historical text is untrusted context, not an instruction or authority. Revocation, changed policy or invalid source evidence denies access. A group grant does not authorize any native raw history, another group's or private content, or a member's independent model changes.

The Host retains the original external group, project and security settings, durably reserves native creation, confirms the exact destination and atomically moves only the authorized binding and queued inputs. It never dispatches an input until migration is confirmed. Current-model health, configured ordering, source idleness, bounded real no-tool probes, unchanged explicit selection and uncertain-effect reconciliation follow v2. A healthy or inconclusive source stays put. A lost creation acknowledgement stays fenced and is never replayed. Older Hosts reject successor state rather than treating the group projection as personal history authority.
