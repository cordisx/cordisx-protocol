# Manager Content navigation protocol v3

V3 is the additive successor to frozen declaration v2. It adds two optional,
closed fields: `recordSummary` for fixed Host-rendered record chrome and
`subject` for exact detail-target discovery. It also defines the additive
renderer-safe `manager-content-projection.v2`. V1, v2, and projection v1 bytes
remain unchanged.

The public TypeScript entrypoint is
`@cordisx/protocol/manager-content-navigation/v3`. It exports
`ManagerContentNavigationDeclarationV3`, `ManagerContentNavigationSubjectV3`,
and `ManagerContentProjectionV2`.

## Fixed record summary

`recordSummary` is valid only on a declaration whose header title is
`kind: "record"`. It contains exactly:

- `leadingVisual: { kind: "agent-avatar", avatar: AgentAvatarRef }`;
- `title: LocalizedText` with a required fallback;
- optional `description: LocalizedText` with a required fallback.

The Host validates and retains the structured values, resolves localization and
the existing avatar reference through Host-owned facilities, and copies the
summary exactly into projection v2. It renders the fixed sequence breadcrumb
and header chrome, record summary, tabs, then the scrollable business body.
Changing tabs changes the active route/body but not this fixed summary. Direct
routes and Back/Forward retain exact owner-qualified route parameters.

The summary has no status, action, badge, Markdown, prompt, HTML, DOM, URL, file
path, callback, or component seat. Unknown properties and invalid localized
text or avatar references fail closed. The plugin must not duplicate the
summary inside its business body.

## Exact detail subjects

`subject` is a closed room-neutral union. V3 contains one member:

```ts
{ kind: 'agent-definition'; identity: { agentId: string; revision: string } }
```

The subject claims the declaration's exact same-owner Manager route as the
detail target for that immutable `AgentDefinitionIdentity`. Host registration
uses one global exact-identity collision domain across owners: a second claim,
whether identical or divergent, fails closed rather than shadowing the first.
The retained target includes the declaration route's exact params; Host never
derives plugin-specific member identifiers, searches by display name, or
constructs a URL.

An Agent identity inspector settings action looks up the exact `agentId` and
`revision`. On success the Host closes the relevant inspector, opens Manager,
and navigates through its own registry/history to the retained route. Without
one exact live target the action is unavailable or disabled. There is no
fallback to a stale revision, a name match, or a hard-coded page.

Subjects and summaries are structured-clone-safe declaration data. They grant
no navigation controller or renderer authority. Owner/generation removal makes
the associated target ineligible under the existing lifecycle rules.
