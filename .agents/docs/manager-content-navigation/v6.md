# Manager Content navigation v6

V6 extends declaration v5 and introduces renderer-safe projection v5. Their
only new data is the read-only record summary. All previous versions stay
frozen. The public entrypoint is
`@cordisx/protocol/manager-content-navigation/v6`.

The summary remains Host-rendered before tabs and requires an exact record
header. In addition to the existing Agent avatar, `leadingVisual` accepts the
generic collection v2 `identity` visual: bounded raster avatar bytes with a
platform icon, or the platform icon alone. Host owns clipping, image failure
fallback, contrast and geometry.

Optional `statuses` (maximum four) and `metrics` (maximum eight) contain unique
local ids, localized labels with fallbacks, brand icons and semantic tones.
Metrics additionally carry non-negative safe integer counts. Host formats
counts using the active locale and renders a compact wrapping summary. The
exact summary data is copied to projection v5. Selecting a tab does not remove
the summary. Replacing the owner's projection may update its live data.

No actions, callbacks, custom components, markup, URLs, credential values or
private account references are admitted. Visuals grant no routing or mutation
authority. Unknown fields, duplicate ids, invalid counts and missing fallbacks
fail closed. Owner/generation disposal retires the summary with its declaration.

Consumers must use v6 only on a Host advertising the successor capability. An
older Host may retain its frozen summary or omit unsupported summary data; it
must not reinterpret v6 as an older tuple or render plugin-owned page chrome.
